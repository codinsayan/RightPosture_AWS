## Result

- `core/live/ExerciseEngine.kt` — `ExerciseEngine`, `FrameResult`, `ExerciseStatus`, `QualityBand`,
  `qualityBand`. Wires 1.2 through 4.5 into one immutable per-frame result.
- `core/reference/BundleAssembly.kt` — `bundleFromAuthoring`, the join between the authoring half
  and the live half. Derives `theta_start`, `theta_peak`, `critical_window` and `v_ref`.
- `AuthoringResult` now carries `meanVisibility`.
- `exercise/ExercisePanel.kt` — quality bar, rep counter, set score, status line, cue text.
- `ReferenceReviewScreen` offers "Use this — start exercise" on an accepted reference only.
- `CameraPreviewScreen` runs the engine on the analysis thread and samples its state at 30 Hz.
- `ExerciseEngineTest` — 11 cases.

Commands:

- `gradlew.bat testDebugUnitTest --no-daemon` — BUILD SUCCESSFUL; 329 tests, 0 failures
  (11 in `ExerciseEngineTest`).
- `gradlew.bat compileDebugKotlin --no-daemon` — BUILD SUCCESSFUL.

Device gate: **not yet run.** Needs a phone: record a reference, accept it, tap "Use this", and
confirm the bar tracks the movement while fps and inference latency stay where 2.2 left them.
