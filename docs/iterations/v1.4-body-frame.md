# Version 1.4 — Body frame

Status: complete  
Source: §6.4

Scope: Gram–Schmidt basis, world-to-body transform, reuse and invalid rules.

Tests: orthonormality, known transforms, 0.10 m and 0.05 m guards.

Gate: deterministic JVM tests pass.

## Result

- Added `core/pose/BodyFrame.kt`: `BodyFrame` (the three basis vectors plus `toBody`), `build` for
  the per-frame construction, and `BodyFrameTracker` for the cross-frame reuse rules.
- Gram–Schmidt is applied as §6.4 requires. Hip-to-hip is not exactly perpendicular to the torso
  axis once pelvic tilt and landmark noise are present; without orthogonalisation the basis inverse
  is not its transpose and every projected angle carries a posture-dependent shear. A test feeds a
  deliberately tilted pelvis and asserts the resulting axes are still orthonormal.
- Invariance is tested directly rather than inferred from orthonormality: the same arm position is
  fed with the body yawed 90° in the world and must produce identical body coordinates. A second
  test translates the whole person and asserts the basis is unchanged. Those two properties are the
  entire purpose of the frame.
- All three §6.4 degeneracy guards implemented: torso `|yRaw| < 0.10 m`, hip projection
  `|xOrth| < 0.05 m`, and any of the four construction landmarks below 0.5 visibility. Note this is
  0.5, not the 0.6 `VIS_MIN` used elsewhere — §6.4 sets a separate, looser bar for frame
  construction, so it is a separate parameter.
- Reuse is expressed as a three-state result (`FRESH`, `REUSED`, `INVALID`) rather than a nullable
  frame. `REUSED` is normal and expected in sagittal-view exercises, whereas `INVALID` means
  abstain; collapsing both into null would lose the distinction that §1.6 needs.
- The 500 ms limit is measured from the last *fresh* frame, not from the first degenerate one, and
  a test asserts the window restarts after each good frame.
- No smoothing in this iteration, per the iteration plan. §6.4 also asks for One Euro filtering of
  the basis vectors; that lands in 2.3 alongside the rest of the live filter.
- Gate: `gradlew.bat testDebugUnitTest --no-daemon --rerun-tasks` passed; 42 tests, 0 failures
  (13 in `BodyFrameTest`).
- `core` still imports no Android APIs. No phone test required.
