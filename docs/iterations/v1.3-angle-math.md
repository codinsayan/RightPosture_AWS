# Version 1.3 — Stable angle math

Status: complete  
Source: §6.5.1–6.5.2, §6.22

Scope: atan2 unsigned and signed planar angles with numerical guards.

Tests: 90°, near-180°, signs, zero vectors, wrap and non-finite inputs.

Gate: JVM tests pass.

## Result

- Added `core/pose/Angles.kt` with `jointAngleDegrees` (§6.5.1) and `signedPlanarAngleDegrees`
  (§6.5.2), plus `dot`, `cross`, `times` and `length` on `Vec3`.
- Both functions use the `atan2` form. §6.5.1 is explicit that `acos(v1·v2 / (|v1||v2|))` loses
  several degrees of precision on float32 near full extension, which is exactly where
  knee-extension exercises live. A test drives 179°, 179.5° and 179.9° and asserts accuracy to
  0.01° so any future switch to `acos` fails loudly.
- Invalidity is represented as `Float?` rather than a new result type. Nothing downstream exists
  yet to consume a richer type, and §1.6 will define the real validity contract.
- Guards implemented from §6.22: `|v| < 1e-6` invalid, `|θ| > 90°` on the signed angle invalid as a
  probable wrap, and any non-finite result invalid. The non-finite check catches NaN landmarks,
  which pass the length guard untouched because `NaN < 1e-6` is false.
- The plane normal is normalised inside `signedPlanarAngleDegrees` rather than assumed unit. Callers
  in §1.4 will build the body basis by Gram–Schmidt, and a silently non-unit normal would scale the
  `cross · n̂` term and skew every signed reading.
- Thresholds went into `Params.kt` as `MIN_VECTOR_LENGTH` and `SIGNED_ANGLE_MAX_DEGREES` so §7 stays
  the single tuning surface.
- Gate: `gradlew.bat testDebugUnitTest --no-daemon --rerun-tasks` passed; 29 tests, 0 failures
  (12 in `AnglesTest`).
- `core` still imports no Android APIs. No phone test required.
